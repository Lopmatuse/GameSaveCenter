# GameSaveCenter 0.6.14 UI 控件一致性修复

本轮基于用户提供的 0.6.13 Git 仓库实施，不重写业务链路。

## 修复范围

- 首页统计卡片内容对齐与“需要关注”交互简化。
- 任务状态、游戏、类型筛选器默认值显示。
- 任务进度条和百分比在缩放时的完整显示。
- 修改器导入工具栏、设置迁移按钮的统一高度和间距。
- DataGrid 列宽拖动热区在浅色主题下的视觉隐藏。
- DataGrid 长内容的列宽调整、Tooltip 与自动横向滚动。
- 全局纵向/横向滚动条 Thumb 边缘裁切。
- 设备状态页签跨页面泄漏。

## Windows 回归重点

1. 大型游戏列表、异常日志、媒体表格和存档历史的纵向 Thumb 在顶部、居中、底部均为完整圆柱形。
2. 任务筛选三个下拉框首次进入均显示“全部”。
3. 任务表格 0%、40%、100% 均完整显示；缩小窗口后出现横向滚动而不是截断百分比。
4. DataGrid 表头列宽可拖动，但浅色主题不显示白色竖条。
5. 维护中心显示“诊断 / 设备状态 / 异常与日志”；其他工作区不显示“设备状态”。
6. 修改器导入三个按钮和设置导入/导出按钮高度、基线一致。
