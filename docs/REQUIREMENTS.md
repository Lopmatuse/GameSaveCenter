# 功能需求规格

## 1. 产品定位

GameSaveCenter 不是新的存档复制引擎，也不是新的游戏平台。它在 Playnite 上提供统一控制层，并通过 Worker 编排 Ludusavi、媒体同步和 Rclone。

## 2. 用户故事

- 我从 Playnite、Steam、Xbox、Epic、Ubisoft、EA、GOG、桌面快捷方式或 MOD 管理器启动游戏时，系统都应尽量识别本次游戏会话。
- 游戏运行期间，系统按策略检查并备份变化的存档；退出后执行最终备份。
- 系统必须告诉我备份是否真的生成、大小是否合理、是否已上传云端。
- 恢复前必须保护当前版本，并能撤销。
- 新截图和录像只同步一次；源文件后来被删除时，归档默认仍保留。
- 无法识别的存档和媒体要进入待确认队列，而不是静默遗漏或猜测覆盖。

## 3. 非功能需求

- 本地优先；无后台账号服务依赖。
- 默认中文 UI，同时保留可本地化结构。
- 插件 UI 不阻塞 Playnite 主线程。
- Worker 长任务串行化或受控并发，防止重复备份同一游戏。
- 所有调用外部程序均使用参数列表/转义，不拼接不可信 shell 字符串。
- 配置原子写入，数据库支持崩溃恢复。
- 日志脱敏。
