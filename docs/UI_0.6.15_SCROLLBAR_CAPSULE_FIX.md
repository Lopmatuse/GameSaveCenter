# GameSaveCenter 0.6.15 滚动滑块双端圆弧修复

本版本以 0.6.14 为基线重新实现滚动滑块；之前生成的 0.6.15 补丁未被应用，不属于本次提交前置条件。

## 根因

旧模板使用单个 `Border CornerRadius` 作为 Thumb 外观。在 Playnite 宿主、不同 DPI、DataGrid/ListBox/ScrollViewer 的实际测量与像素取整组合下，模板视觉可能在一端落到控件边界上，造成顶部仍是圆弧、底部却呈直线的现象。仅隐藏轨道或增加 Track 边距不能保证修复。

## 新实现

- 纵向 Thumb 不再依赖单个 Border 圆角。
- 纵向滑块由“顶部圆形端帽 + 中间矩形 + 底部圆形端帽”组成。
- 横向滑块由“左端圆形端帽 + 中间矩形 + 右端圆形端帽”组成。
- 可见形状在 Thumb 控件内部额外内缩，避免宿主视口、Track 或高 DPI 像素取整裁切端帽。
- 正常状态不绘制轨道线，仅保留透明的分页点击区域。
- 游戏列表、存档、媒体、任务、异常日志、ComboBox Popup 与其他 ScrollViewer 继续复用同一隐式 ScrollBar 样式。

## 回归重点

在 100%、125%、150%、200% DPI 下分别检查滑块位于顶部、中部和底部时：

1. 上下两端均为完整半圆弧。
2. 不出现下端直线、削平、缺口或尾线。
3. Thumb 拖动、滚轮、点击空白轨道翻页仍正常。
4. 横向滚动条左右两端同样完整。
