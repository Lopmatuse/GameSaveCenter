# Apple HIG 启发的 WPF 界面规范

更新时间：2026-07-28
适用版本：`0.5.0-development-preview`

完整实现约束以 `APPLE_WPF_IMPLEMENTATION_PROMPT.md` 为准；任何新增或修改 UI 的提交还必须通过 `UI_CHANGE_GATE.md`。

GameSaveCenter 是 Playnite 内嵌 WPF 插件页面，不拥有 Playnite 外层窗口。因此不伪造 macOS 红黄绿窗口按钮，也不强行修改 Playnite 标题栏。设计目标是借鉴 macOS/iPadOS 的层级、留白、圆角、克制色彩和微动效，而不是逐像素复制某个系统窗口。

## 视觉层级

1. **背景层**：保持透明以继承 Playnite 主题，叠加低透明度紫蓝与绿色环境光。
2. **玻璃层**：侧栏、数据卡片和详情面板使用主题自适应半透明渐变、细边框和柔和阴影。
3. **内容层**：正文始终使用 Playnite 的 `TextBrush`，避免深色主题黑字、浅色主题白字。
4. **强调层**：紫色只用于当前选择和主要操作；绿色、红色、橙色分别用于成功、失败和警告。

## 毛玻璃边界

WPF 内嵌 `UserControl` 无法可靠获得宿主窗口的真实 backdrop blur。当前实现采用“拟态毛玻璃”：

- 半透明主题自适应渐变表面；
- 模糊后的环境光色块；
- 细高光边框；
- 克制阴影；
- 内容本身不使用 `BlurEffect`，避免文字模糊。

真正的 Windows Acrylic/Mica 需要控制顶层 HWND；本插件页面不应越权修改 Playnite 主窗口。

## 主题与辅助功能

- 自动根据 `TextBrush` 亮度判断浅色/深色主题并生成玻璃色板。
- 高对比度模式自动关闭环境光和半透明表面，改用不透明主题背景。
- 遵循 Windows“在 Windows 中显示动画”设置。
- 设置页允许单独关闭界面动画、关闭毛玻璃，或调整毛玻璃强度 20–100%。

## 动画规范

| 场景 | 效果 | 时长 |
|---|---|---:|
| 页面打开 | 上移 16px + 淡入 | 280–320ms |
| 游戏切换 | 详情从右侧 13px 淡入 | 230ms |
| 标签切换 | 内容从右侧 10px 淡入 | 200ms |
| 任务选择 | 任务详情从右侧 8px 淡入 | 200ms |
| 指标卡悬停 | 上浮 3px | 160ms |
| 导航悬停 | 向右移动 3px | 140ms |
| 按钮悬停 | 缩放到 1.025 | 130ms |
| 按钮按下 | 模板内缩放到 0.97 | 即时状态反馈 |
| 状态变化 | 状态胶囊轻微淡入与缩放 | 180ms |

动画只修改 `Opacity` 和 `RenderTransform`，避免反复触发布局。

## 页面结构

- 左侧固定应用侧栏：品牌、功能导航、Worker/Ludusavi 状态。
- 顶部：页面标题、忙碌状态、刷新/全部备份/同步媒体。
- 中部：六个状态指标卡。
- 主区域：游戏列表 + 当前游戏详情。
- 详情标签：存档历史、截图与录像、候选路径、任务、诊断、异常与日志。
- 底部：Worker、Ludusavi、备份格式与更新时间胶囊。

## 禁止事项

- 不给每个控件画高饱和蓝色粗边框。
- 不使用默认 WPF 方形按钮。
- 不在深色主题写死黑色文字。
- 不对包含文字的容器施加模糊效果。
- 不使用持续弹跳、强烈弹簧或大幅缩放。
- 不因为追求毛玻璃而牺牲高对比度和可读性。
