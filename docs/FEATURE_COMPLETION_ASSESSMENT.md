## 已经实现的核心功能

### 修改器与游戏工具

- 每游戏多个修改器、多个 Cheat Table 和多版本 SQLite 模型。
- EXE、ZIP、目录和 CT 本地导入、SHA-256、Zip Slip 防护和文件缺失状态。
- 每项独立启用、手动启动、自动启动、延迟、管理员权限和退出关闭。
- FLiNG 应用内目录缓存、搜索、版本读取、下载、安全解压和自动绑定。
- 常见反作弊线索默认阻止自动启动；不提供绕过、Defender 关闭或白名单。

### 工程与安装

- 完整 Git 历史、中文提交和固定英文作者。
- Windows build/test/publish/package/dev-install 流程。
- 一键构建安装运行、动态版本、实际目录发现、原子替换和安装版本核验。
- 跨平台 JSON/XML/YAML/XAML/C# 结构门禁。
- Apple-inspired WPF 规范和 UI 变更门禁已经落库。

### 存档与任务

- Ludusavi 健康、匹配、单游戏/全部/退出/游玩中定时备份。
- ZIP 多版本、压缩和完整/差异保留参数。
- 历史索引、备注、锁定、差异、保留预览。
- 任务队列、进度、取消、Worker 重启遗留任务修复。
- 真实错误码、stdout/stderr 诊断、复制详情。
- 失败/取消的 Backup、MediaSync 安全重试。

### 恢复与校验

- 文件数量、体积、零字节和异常下降校验。
- PreRestore、恢复确认、恢复后校验、失败回滚和撤销恢复源码。
- 自动恢复始终关闭。

### 游戏识别

- Playnite 启动/退出事件。
- 外部进程、安装路径、Game Action 和常见 MOD loader 识别。
- 未匹配游戏的启动前/退出后有界文件快照。
- 候选评分、解释、持久化、接受草案和忽略流程。
- Xbox WGS 辅助候选。

### 媒体与云端

- Steam、Game Bar、Windows、平台相邻目录和自定义媒体来源。
- 稳定写入、原子复制、SHA-256 去重和重新归类。
- 公共媒体文件名匹配、无重叠会话时间窗口、全局待归类收件箱、人工归类和忽略保留副本。
- Rclone `copy/check` 安全单向适配。

### UI

- Apple-inspired 六工作区与 Settings 信息架构、圆角阅读表面、局部毛玻璃环境光和克制微动效。
- 跟随 Playnite、固定浅色、固定深色。
- 高对比度、关闭动画和关闭玻璃降级。
- 大型游戏库搜索、筛选、排序和 Recycling 虚拟化列表；紧凑窗口保持滚动或横向访问而非裁切功能。
- 任务详情、诊断中心、空状态和真实错误展示。

## 仍未完整实现的功能

### P0：必须在继续扩功能前完成的真实验证

1. 在 Windows 编译、安装当前版本，修复所有真实 C#/XAML 错误。
2. 连续产生至少三个 ZIP 历史版本并确认历史、刷新和重启后仍一致。
3. 使用可丢弃存档跑通恢复、PreRestore、失败回滚和撤销恢复。
4. 验证 Worker 重启后设置、任务、历史和候选均不丢失。
5. 在多套 Playnite 主题和 100%–200% DPI 下完成 UI 回归。

### P1：重要未闭环功能

1. 任务变化已接入 Worker 最佳努力事件管道，并保留信号唤醒的有界长轮询；仍需验证 Playnite 关闭面板、Worker 重启和长任务高频进度下的稳定性。
2. Rclone 上传、游戏级状态和失败重试已闭环；仍需真实远端验证 `copy/check`、断网恢复、取消及恢复闸门。
3. 公共截图会话归类与全局收件箱的真实文件时间、性能和交互调优。
4. 未匹配游戏会话快照的性能、扩展名、目录深度和阈值调优。

### P2：高级功能

1. 多设备分叉历史已支持人工决策、远端隔离下载、校验和受保护恢复；仍缺两个真实设备与 Rclone 后端的完整回归。
2. 未知进程、通用启动器和 MOD 链人工学习已实现，仍缺多类真实 loader 回归。
3. 自动保留清理执行；当前只给出安全预览。Ludusavi 公开 CLI 未提供删除单个版本的稳定操作，因此继续保持不自动删除的安全边界。
4. 媒体收藏、备注、存储统计、批量元数据、虚拟化缩略图缓存和视频内嵌预览已实现；仍需真实编解码器与大库回归。
5. 配置导入/导出和缺失路径迁移报告已实现；Playnite 官方更新清单已准备，仍需 Release 资产和 Add-ons 数据库 PR。
6. Playnite Add-ons 数据库发布和长期版本兼容测试。

## 下一阶段建议

在用户恢复 Windows 测试前，源码开发优先顺序为：

1. 完成 0.6.5 的 Playnite 后台通知、云端重试和修改器多入口真机回归。
2. 使用可丢弃存档完成恢复、回滚与撤销恢复证据。
3. 媒体收件箱与公共截图会话归类的 Windows 真机调优。
4. 设计多设备冲突的人工选择流程，但继续禁止自动覆盖。

用户可测试后，立即暂停新增功能，先完成 P0 真机闭环。只有恢复与撤销恢复通过后，才应把“可安全日常使用度”提高到 65% 以上。
