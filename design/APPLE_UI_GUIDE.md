# Apple HIG 启发的 Windows/Playnite UI 规范

本项目借鉴的是设计原则，不复制 Apple 商标、专有图标或 macOS 窗口装饰。

## 原则

1. **内容优先**：标题清晰，关键状态不依赖装饰。
2. **层级明确**：侧边栏、内容区、检查器三层；同级内容用分组和留白而不是大量边框。
3. **材质克制**：仅在顶栏、侧栏或浮层使用半透明/模糊感；正文保持稳定可读。
4. **圆角统一**：卡片 14–18px，按钮 9–12px，状态胶囊使用全圆角。
5. **语义颜色**：正常、警告、错误、进行中均配文字与图标，不只靠颜色。
6. **轻量动效**：150–220ms 淡入、位移和状态过渡；尊重系统减少动态效果设置。
7. **Windows 原生性**：键盘焦点、缩放、屏幕阅读器和 Playnite 主题兼容优先。

## 页面结构

- 左侧：总览、游戏、存档、媒体、任务、异常、设置。
- 中间：当前页面主列表或时间线。
- 右侧：选中游戏/版本/媒体的详情检查器，可折叠。

## 控件

- Primary Button：仅用于当前页面最主要动作。
- Secondary Button：浅底或描边。
- Destructive Button：恢复覆盖、删除等操作需二次确认。
- Metric Card：只展示短标签、关键数字和辅助说明。
- Status Pill：图标 + 明确文字。
